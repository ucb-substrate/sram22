| Trace | Meaning |
| --- | --- |
| CLK | External clock; access starts after its rising edge |
| PC_B | Active-low precharge control |
| WLEN | Enable applied to the row-address gating |
| WL[0] | Selected wordline after the decoder |
| BL[0], BR[0] | Main-array bitline pair |
| SAEN | Sense-amplifier enable |

After CLK rises, PC_B rises to disable precharge. WLEN then asserts and the selected
wordline rises after decoder delay. The main bitlines develop a differential.
WLEN falls first; WL[0] falls near the subsequent SAEN transition. Finally PC_B
falls and the bitlines return toward their precharged levels.

## Replica timing

The replica bitline is **not plotted here**. In the implementation, replica
bitline detection resets the wordline-enable path during reads. A delay chain then
sequences sensing and precharge. One row of replica cells is driven by `rwl`; the
other replica wordlines are tied low and contribute load.

The mechanism is intended to track array behavior across operating conditions.
This image does not demonstrate a particular replica trip voltage, replica/main
tracking accuracy, or sensing margin across all PVT corners. See
[Algorithms](/docs/internals/algorithms/#self-timed-control) for the source-derived
sequence and [Timing diagrams](/docs/interface/timing/) for characterized Liberty constraints.
