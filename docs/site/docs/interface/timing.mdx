SRAM22 is a synchronous SRAM: every input is captured on the **rising edge** of
`clk`, and `dout` updates after that edge. The diagram below shows a read cycle
followed by a write cycle.

<TimingDiagram />

## Reading the diagram

On the **read** edge, `ce = 1` and `we = 0`. The address must be stable for the
setup time `t`<sub>SU</sub> before the edge and the hold time `t`<sub>H</sub>
after it. The macro then self-times the access — disabling precharge, pulsing
the wordline, and firing the sense amplifiers — and drives the result onto
`dout` after the clk-to-Q delay `t`<sub>clk→Q</sub>.

On the **write** edge, `ce = 1` and `we = 1`. `addr`, `din`, and `wmask` must
meet the same setup/hold window. Only the data groups whose `wmask` bit is set
are updated.

## Self-timed sequence

The macro derives its internal pulses from a replica bitline rather than an
external strobe. During a **read** the control logic:

1. Latches `addr` and the control inputs.
2. Disables precharge and the sense-amp enable.
3. Decodes the address and turns on the selected wordline (`wlen` pulse).
4. Turns the wordline off once the **replica bitline** discharges to ≈ VDD/2.
5. Fires the sense amplifiers (`saen`) and captures the result.
6. Re-enables precharge.

See [Waveforms](/docs/internals/waveforms/) for the measured replica-vs-main
bitline behavior that sets this timing.
