**SRAM22** is a configurable SRAM generator developed at UC Berkeley. Given a
short TOML description — depth, word width, column-mux ratio, and write
granularity — it parametrically generates an SRAM macro
for the [SkyWater **SKY130**](https://skywater-pdk.readthedocs.io/) open process.

The generator emits these views:

- **GDS** layout
- **LEF** abstract (for place-and-route)
- **SPICE** netlist
- **Verilog** behavioral model
- **Liberty** timing at TT, SS, and FF (interpolated by default)

:::note[Process support]

SRAM22 currently targets the **SKY130** process only. It is an active research
project; use generated macros at your own risk.

:::

The [quickstart](/docs/quickstart/#liberty-timing) describes the interpolation
model's supported configurations and optional commercial characterization.
Run DRC/LVS and timing checks for your generated configuration and integration.

## Architecture at a glance

SRAM22 builds a self-timed SRAM around one 6T bitcell array with shared column
peripherals and replica-based timing control. Address, data, and access controls
are captured on the rising clock edge. Physical reset is asynchronous. Replica
bitline detection ends the read wordline pulse, followed by delayed sensing and
precharge. The output uses a differential latch.
