**SRAM22** is a configurable SRAM generator developed at UC Berkeley. Given a
short TOML description — depth, word width, column-mux ratio, and write
granularity — it parametrically generates a complete, DRC/LVS-clean SRAM macro
for the [SkyWater **SKY130**](https://skywater-pdk.readthedocs.io/) open process.

Each generated macro comes with every view a physical-design flow needs:

- **GDS** layout
- **LEF** abstract (for place-and-route)
- **SPICE** netlist
- **Liberate `.lib`** timing across PVT corners
- **Verilog** behavioral model

:::note[Process support]

SRAM22 currently targets the **SKY130** process only. It is an active research
project; use generated macros at your own risk.

:::

## Architecture at a glance

SRAM22 builds a self-timed SRAM around a 6T bitcell array with a divided
wordline / divided bitline organization, four-way banking, and replica-based
timing control. Inputs are latched on the rising clock edge; a replica bitline
turns the wordline pulse off and fires the sense amplifiers.
