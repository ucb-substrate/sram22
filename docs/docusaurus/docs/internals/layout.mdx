## Floorplan

The macro is organized into a few recognizable regions (positions below refer to
the default view):

- **Bitcell array** — the large, highly regular block on the upper right. Each
  row is a wordline; each column a bitline pair. This is where the data lives,
  and it dominates the area.
- **Predecoders & row decoder** — the striped blocks along the top left. They
  decode the row address bits and drive the wordlines into the array.
- **Timing control logic** — the irregular block in the middle left. This is the
  self-timed controller that sequences precharge, the wordline pulse, the
  replica bitline, and the sense-amp enable.
- **Column circuitry** — the horizontal bands directly below the array:
  precharge, the column mux, sense amplifiers, and write drivers serving the
  single array.
- **Input flip-flops** — cells that capture `addr`, `din`, `wmask`, and access
  controls. The sense-amplifier outputs feed **differential latches** that hold
  `dout`; there is no separate clocked output flip-flop.

:::note[About this view]

Layers are drawn with representative colors (nwell, diff, poly, li1, met1,
met2); contacts and vias are omitted for clarity. The view is rendered from
the macro's GDS. Pin shapes for the same macro are in
<a href="/docs/interface/pin-positions/">Pin positions</a>.

:::

The block measures **{pins.um_width.toFixed(2)} × {pins.um_height.toFixed(2)} µm**. Recall that it is meant to be
