Address, data, and access controls are captured on the rising clock edge.
Physical reset is asynchronous; the behavioral Verilog model checks `rstb` at the
clock edge. Neither reset nor a disabled access initializes the stored data or `dout`.

<TimingDiagram />

With `rstb = 1` and `ce = 1`, `we = 0` reads and `we = 1` writes. A read updates
`dout` after the internal access delay; a write changes only the groups enabled by
`wmask`. Each input must meet **its own** rise/fall setup and hold constraints.
The diagram is not to scale and omits reset and mask traces for clarity.

## Characterized constraints

These values come from the [published Liberty file](https://github.com/ucb-substrate/sram22_sky130_macros/blob/75cbe961e18ee00d5a6c73fa455505f0bcdf4c05/sram22_64x32m4w8/sram22_64x32m4w8_tt_025C_1v80.lib)
for <code>{timing.macro}</code> at **{timing.corner_label}**.
Each range spans every entry of the corresponding rise- or fall-constraint table,
including both slew axes. “Rise/fall” below refers to the **input transition**;
all these setup/hold arcs are relative to a rising clock edge. Use the full Liberty
tables and the actual signal slews in STA.

## Internal sequence

The clock pulse disables precharge and sense enable, then enables the gated
row-address path. Replica bitline detection ends the read wordline-enable pulse;
a decoder-replica delay sequences sensing and subsequent precharge. The output
is retained by a differential latch. See
[Algorithms](/docs/internals/algorithms/#self-timed-control) for the implementation
and [Waveforms](/docs/internals/waveforms/) for an illustrative main-bitline plot.
